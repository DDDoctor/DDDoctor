# 发布说明 · MultiView v1.0.5

**发布日期**：2026-09-12
**平台**：Windows 10 / 11 x64
**技术栈**：Python 3.13 + PySide6 6.11 + python-vlc 3.0.21203（内置 VLC 3.0.23 运行库）

---

## 1. 发布产物

| 文件 | 大小 | 说明 |
| --- | --- | --- |
| `MultiView-1.0.5-win64.zip` | 约 103 MB | **推荐**。解压后运行 `MultiView\MultiView.exe` |
| `MultiView-1.0.5-single.exe` | 约 103 MB | 单文件版。每次启动需解包约 232 MB，慢 5~15 秒 |
| `config.sample-11ch.json` | 4 KB | 11 路轨道车辆摄像头配置样例 |
| `MultiView-1.0.5-source.zip` | 约 0.2 MB | 源码 + 工具 + 文档（不含 VLC 运行库） |

解压后目录结构：

```
MultiView\
├─ MultiView.exe
└─ _internal\
   ├─ vlc\              内置 VLC 运行库（libvlc.dll / libvlccore.dll / plugins）
   ├─ PySide6\
   └─ python313.dll 等
```

**目标机器无需安装 Python 或 VLC**，整个文件夹拷过去即可运行。

## 2. 系统要求

| 项目 | 建议 |
| --- | --- |
| 操作系统 | Windows 10 / 11 x64 |
| CPU | 8 路以内 4 核；18 路建议 8 核 |
| 内存 | **每路约 200–250 MB**，18 路建议 16 GB |
| 网络 | 单路 1080P 约 2–8 Mbps，18 路需 40–150 Mbps 稳定内网 |
| 显卡 | 支持 D3D11 硬解（默认开启，比软解省约 1/3 CPU） |

## 3. 部署与首次运行

1. 把 `MultiView-1.0.5-win64.zip` 解压到任意目录（**不要放在 `C:\Program Files`**，
   否则配置会写到 `%APPDATA%\MultiView`）；
2. 双击 `MultiView.exe`；
3. 首次运行会自动生成一份演示配置（`screen://` 桌面捕获 + 两路公开测试流），
   点「▶ 播放全部」即可验证环境；
4. 点「配置…」填写自己的通道地址；或先点「批量导入地址…」粘贴；
5. 当前通道 → 点工具栏「🎧 仅此路出声」来指定哪一路出声。

## 4. 从旧版本升级

* 直接解压覆盖到新目录即可，**配置是独立的 `config.json`**，拷过去即可复用；
* v1.0.5 载入旧配置时会**自动把截图/录制目录从绝对路径改成相对路径**，
  这样就不会再写回旧版本目录；
* 若旧配置放在 `%APPDATA%\MultiView`，把它复制到新程序目录即可。

## 5. 本版主要变化

### 新增
- 截图 / 录制目录改为**相对程序目录**，换版本自动跟随；
- 载入旧配置时**自动迁移**绝对路径；
- 画面标题栏显示声音状态（🔊 / 🔇）；
- 工具栏「🎧 仅此路出声」、「🔇 当前通道静音」（`Ctrl+M`）。

### 修复
- 录制写到旧版本目录的问题。

> v1.0.1–v1.0.4 的修复内容（卡死、双击全屏、僵尸进程等）见根目录 `CHANGELOG.md`。

## 6. 已知限制

| 限制 | 原因 | 规避 |
| --- | --- | --- |
| 开始/停止录制时该路重连约 1 秒 | libvlc 3.x 无录制 API，只能用 sout 管线 | 无（可改用 VLC 4.0） |
| 录制中的通道无法截图 | sout 模式下 VLC 不注册可截图的 vout | 先停止录制 |
| 单文件版启动慢 5~15 秒 | 每次启动要解包 232 MB | 用目录版（zip） |
| 音频只能按通道静音/调音量 | 多路同时出声会互相干扰 | 用「仅此路出声」 |
| `Esc` 之外的快捷键在输入框内无效 | Qt 焦点机制 | 点一下画面再按快捷键 |
